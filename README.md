# TFC Food Port

**TFC Food Port** 是一个将《群峦传说》（TerraFirmaCraft）的食物系统搬运到 **Minecraft 26.1.2 + NeoForge** 的模组。它保留了 TFC 中丰富的食物、种子和奶酪链条，同时大幅简化了获取方式，并针对 **农夫乐事** 和 **森罗物语** 提供了完整的配方适配。

此外，本模组还加入了一些轻松的扩展内容，例如中秋月饼、苹果树稀有掉落和对应果酱，让生存体验更加多样。

---

## ✨ 功能特性

### 🍎 TFC 食物系统
- 搬运了 TFC 中的绝大多数食物物品，仅保留**饥饿值**与**饱和度**，移除了营养、腐败、水分等复杂系统。
- 种子与作物按**原版机制**注册和种植，生长条件只需耕地、水和光照。
- 奶酪链条简化：凝乳酶由原版牛/羊掉落；生奶酪用农夫乐事烹饪锅制作；陈化奶酪通过熔炉/烟熏炉完成。

### 🪣 大桶：流体储罐
- TFC 的大桶被重新设计为一个**无 GUI 的流体储罐**，容量 **1000B（1,000,000 mB）**。
- 手持桶右键即可存入或取出流体，支持水、牛奶等常见流体。
- 合成配方：8 个原版半砖围一圈。

### 🍳 多模组配方适配
模组配方会根据已安装的模组动态切换，确保最佳兼容性：

| 已安装模组 | 使用的配方类型 |
| :--- | :--- |
| 仅原版 | 原版工作台、熔炉等 |
| 仅农夫乐事 | 农夫乐事烹饪锅、切菜板 + 原版备用 |
| 仅森罗物语 | 森罗物语石磨、烹饪锅 + 原版备用 |
| 两者同时安装 | 仅使用农夫乐事和森罗物语的适配配方，原版配方自动禁用 |

### 🧩 通用标签支持
所有配方优先使用 `c` 命名空间的通用标签（如 `#c:tomatoes`、`#c:flour`），并为你自己的食物物品添加对应标签。这样其他农业模组的同类食材也能用于合成，反之亦然。

### 🥮 中秋彩蛋
- 添加了多种口味的**月饼**：莲蓉、豆沙、五仁、蛋黄、冰皮、水果等。
- 食用后获得**数秒的增益 Buff**，不同口味对应不同效果。
- 配套的**果酱**系统，可用农夫乐事烹饪锅制作，并作为月饼的合成材料。

### 🍏 苹果树稀有掉落
- 苹果树树叶有概率掉落**金苹果**（5%）和**附魔金苹果**（1%）。
- 掉率可在配置文件中调整。

## 📦 安装要求

- **Minecraft**：26.1.2
- **加载器**：NeoForge（对应版本 26.1.2+）
- **必需依赖**：无
- **可选依赖**：
  - [农夫乐事 (Farmer's Delight)](https://www.curseforge.com/minecraft/mc-mods/farmers-delight)
  - [森罗物语 (Kaleidoscope Cookery)](https://www.curseforge.com/minecraft/mc-mods/kaleidoscope-cookery)

> 模组会检测上述模组是否存在，并自动启用对应的配方集。没有它们时，模组也能独立运行，使用原版配方。

---

## 🔧 配置

模组提供简单的配置文件（`config/tfc_food_port-common.toml`），可调整：

- 苹果树掉落金苹果的概率
- 附魔金苹果的概率
- 大桶容量（默认 1000B）
- 月饼 Buff 持续时间与等级
