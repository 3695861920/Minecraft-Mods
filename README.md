# TFC Food Port

**TFC Food Port** 是一个将《群峦传说》（TerraFirmaCraft）的食物系统搬运到 **Minecraft 26.1.2 + NeoForge** 的模组。它保留了 TFC 中丰富的食物、种子和奶酪链条，同时大幅简化了获取方式，并接入了 **农夫乐事** 的烹饪锅与切菜板。

此外，本模组还加入了一些轻松的扩展内容，例如中秋月饼、苹果树稀有掉落和对应果酱，让生存体验更加多样。

## ✨ 功能特性

### 🍎 TFC 食物系统
- 搬运了 TFC 中的绝大多数食物物品，仅保留**饥饿值**与**饱和度**，移除了营养、腐败、水分等复杂系统。
- 数值按**农夫乐事**的曲线重新平衡，不再沿用 TFC 全员饥饿值 4 的设定：生食材 1–3、熟食 5–6、面包 6、三明治 8、沙拉 6、汤与锅菜 12。
- 种子与作物按**原版机制**注册和种植，生长条件只需耕地、水和光照。
- 奶酪链条简化：凝乳酶由原版牛/羊掉落；生奶酪用农夫乐事烹饪锅制作；陈化奶酪通过熔炉/烟熏炉完成。

### 🪣 大桶：流体储罐
- TFC 的大桶被重新设计为一个**无 GUI 的流体储罐**，容量 **1000B（1,000,000 mB）**。
- 手持桶右键即可存入或取出流体，支持水、牛奶等常见流体。
- 破坏后桶内流体保留（通过数据组件跟随掉落物）。
- 合成配方：8 个原版半砖围一圈。

### 🍳 多模组配方适配（加载阶段动态检测）

每一个“需要厨具”的加工步骤都存在**三份配方**，每份带一个 `neoforge:conditions` 条件，由 NeoForge **在数据包加载阶段**求值决定去留：

| 已安装模组 | 实际生效的配方 |
| :--- | :--- |
| 都没有 | 仅工作台与熔炉（`_vanilla` 变体） |
| 仅农夫乐事 | 农夫乐事切菜板 / 烹饪锅 |
| 仅森罗物语 | 森罗物语切菜板 / 石磨 / 锅 |
| 两者都有 | 两套设备配方**同时**存在（它们是不同机器，玩家可以用任意一种） |

具体用法：

| 用途 | 农夫乐事 | 森罗物语 | 都没有 |
| :--- | :--- | :--- | :--- |
| 作物 → 谷物粒 | 切菜板 | 切菜板 | 工作台 |
| 谷物粒 → 面粉 | 切菜板 | **石磨** | 工作台 |
| 果酱、汤、米饭、奶酪、面团、煮蛋 | 烹饪锅 | 锅（`carrier` 为碗） | 工作台 |
| 切西瓜 / 南瓜 | 切菜板 | 切菜板 | 工作台 |

> 这两个模组都是**可选**依赖。条件在加载时求值，不适用的配方**根本不会进入配方管理器**，而不只是被隐藏。游戏测试会直接读回已加载的配方 id 来断言这一点。

### 🧩 通用标签支持
配方使用 `c` 命名空间的通用标签（如 `#c:foods/fruit`、`#c:foods/dough`），并为本模组的食物物品添加对应成员，因此其他模组的同类食材也能参与合成，反之亦然。

### 🥮 中秋月饼与果酱
- **24 种口味**的月饼：21 种水果系果酱口味（黑莓、树莓、蓝莓、草莓、香蕉、樱桃、苹果、柠檬、橄榄、橙子、桃、李、西瓜、花生等）+ 金苹果 + 附魔金苹果 + 其中一种对应关系见 `Food`/`Mooncake` 枚举。
- 制作分两步：**1 罐果酱 + 4 个面团 → 8 个生月饼**，再把生月饼放进**熔炉或烟熏炉**烤成月饼。面团可用本模组任一种谷物面团或农夫乐事的面团。
- 22 种果酱口味食用后各获得 **5 秒**的单一增益（不同水果对应不同效果）；金苹果与附魔金苹果月饼则完全复刻**原版金苹果与附魔金苹果**的效果，包括更长的持续时间。

### 🍏 苹果树稀有掉落
- 红苹果与青苹果树叶有极小概率掉落**金苹果**（**0.1%**）和**附魔金苹果**（**0.01%**）。
- 这两个掉率**不受时运影响**（刻意为之，避免时运把彩蛋变成常规产出）。
- 树叶本身可用**剪刀或精准采集**挖下并作为方块携带；其余情况只会少量掉落水果（基础 5%，时运每级 +5%）。

## 📦 安装要求

- **Minecraft**：26.1.2
- **加载器**：NeoForge 26.1.2.109+
- **必需依赖**：无
- **可选依赖**：
  - [农夫乐事 (Farmer's Delight)](https://www.curseforge.com/minecraft/mc-mods/farmers-delight) —— 切菜板与烹饪锅配方
  - [森罗物语 (Kaleidoscope Cookery)](https://www.curseforge.com/minecraft/mc-mods/kaleidoscope-cookery) —— 切菜板、石磨与锅配方

> 两个都不装也能完整游玩，所有加工配方会回退到工作台与熔炉。
